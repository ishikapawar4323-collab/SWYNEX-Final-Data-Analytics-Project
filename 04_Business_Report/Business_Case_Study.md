# Passenger Survival Intelligence

## Problem Statement

The objective was to transform raw passenger data into meaningful business insights through an end-to-end analytics workflow.

## Dataset Information

- 891 passenger records
- 12 analytical features
- Public dataset for business analytics practice

## Data Cleaning

- Missing value treatment
- Duplicate removal
- Data validation
- Standardized data types

## Exploratory Analysis

Python was used to identify demographic, socio-economic, and behavioral trends through statistical visualization.

## Interactive Dashboard

A single-page Power BI dashboard was developed using DAX measures, KPI cards, and interactive slicers for executive reporting.

## Business Impact

This project demonstrates practical skills in data cleaning, exploratory analysis, business intelligence, and data storytelling applicable to entry-level Data Analyst roles.
