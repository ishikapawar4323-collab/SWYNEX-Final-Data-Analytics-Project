# SWYNEX Final Data Analytics Project

## Executive Summary

An end-to-end Data Analytics case study completed during the **SWYNEX Data & AI Internship**, covering the complete analytics lifecycle from data cleaning to business intelligence.

## Project Workflow

| Stage | Deliverable |
|--------|-------------|
| Task 1 | Data Cleaning & Preparation |
| Task 2 | Exploratory Data Analysis |
| Task 3 | Interactive Power BI Dashboard |
| Task 4 | Business Analytics Case Study |

## Dataset

- **Source:** Titanic Passenger Dataset
- **Records:** 891
- **Features:** 12

## Executive KPIs

| KPI | Value |
|------|------:|
| Total Passengers | **891** |
| Survival Rate | **38.4%** |
| Female Survival | **74.2%** |
| Median Age | **28 Years** |

## Key Business Insights

- Gender emerged as the strongest survival predictor.
- First-class passengers achieved the highest survival rate.
- Higher ticket fares correlated positively with survival.
- Younger passengers demonstrated stronger survival outcomes.
- Interactive filtering enables multidimensional business analysis.
